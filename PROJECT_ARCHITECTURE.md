# Project Architecture

Clean Architecture layout for **finance-app-go-demo**. Dependency rule: outer layers depend inward; domain has no infrastructure imports.

```
domain  ←  application  ←  adapter / infrastructure
```

---

## Layers

### Domain (`internal/domain`)

Pure Go types: entities, enums, value objects, domain errors, and repository **interfaces**. No frameworks, no DB drivers.

### Application (`internal/application`)

Use-cases orchestrate domain logic through repository and service interfaces (auth tokens, password hashing, sessions, notifier). One `Service` struct per zone, one file per use-case. Depends only on domain (and its own ports). `query/` holds read-model services for list endpoints with filters and sorting.

### Infrastructure (`internal/infrastructure`)

Implements domain ports: Ent/PostgreSQL repositories, Redis sessions and recovery storage, bcrypt passwords, JWT tokens, email notifier.

### Adapter (`internal/adapter`)

HTTP layer: Gin router and handlers (one file per endpoint), request/response DTOs, mappers to domain models, auth and rate-limit middleware, cookie handling. gRPC or other transports can sit beside `http/` later.

### App (`app/`)

Wires config, clients, repositories, use-cases, and the HTTP server. Keeps `main.go` thin.

### Config & migrations

* **`config/`** — loads process env (and `.env` if present) into typed structs
* **`migrations/`** — versioned SQL; applied on PostgreSQL connect via `pkg/postgres`
* **`ent/schema/`** — source of truth for entity shapes; generate with `make ent`

## Domain zones (application packages)

| Package | Responsibility |
|---------|----------------|
| `auth` | Register / login / logout / refresh / verify; password recovery and reset; default categories on register |
| `account` | Create, update, get, list accounts; per-account balance |
| `transaction` | Income and expense lifecycle (create, update, delete, get, filtered list) |
| `transaction_category` | Category create, update, delete, list |
| `transfer` | Create and delete transfers between accounts (multi-currency) |
| `user` | User profile, password change, aggregate balance |
