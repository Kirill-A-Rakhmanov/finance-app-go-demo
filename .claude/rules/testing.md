# Testing

- Every use-case and every handler gets a test file next to it: `x.go` → `x_test.go`.
- Tests live in the external package (`package transaction_test`) and import the code under test.
- Table-driven with `testify`: a `tests := []struct{ name; input; setupMocks; wantErr; wantResult }`
  slice and `t.Run(tt.name, ...)`. Use `require` when the test can't continue after a failure,
  `assert` otherwise. Check errors by identity/kind (`errors.Is` / `apperror` vars), not by string.
- Mocks are generated by mockery from `.mockery.yaml` into `mock/` subpackages next to the
  interface (`domain/repository/mock`, `application/auth/mock`, `application/query/mock`,
  `pkg/transaction/mock`). Import them with the alias `repomock`-style
  (`repomock "finance-app-go-demo/internal/domain/repository/mock"`).
  - Never edit files in `mock/` by hand. When you add or change an interface, add it to
    `.mockery.yaml` and run `make mocks`.
  - Use the expecter API: `repo.EXPECT().GetByIDAndUserID(mock.Anything, id, userID).Return(...)`.
    `mock.Anything` for `ctx`; specific values for everything else.
- Use-case tests cover: the happy path, each business-rule error, validation errors, and repository
  errors being propagated.
- Handler tests build a `gin.New()` router in `gin.TestMode`, mount the handler on a real route
  pattern, and inject the session with the `withSession` helper from `testhelpers_test.go` (a nil
  session simulates an unauthenticated request). The real service is built on mock repositories;
  assert on HTTP status (and body when it matters).
  Every handler test must include: success, no session → 401, bad input → 400, and the
  not-found / forbidden path.
- Any logic that scopes data by user needs a test that another user's resource is not reachable.
- Money assertions use `decimal.Equal`, not `==` or `assert.Equal` on `decimal.Decimal`.
- Integration tests are named `*_integration_test.go`, use testcontainers (Postgres), and live in
  `internal/infrastructure/postgres`. Don't make unit tests depend on Docker.
- Run a single test: `go test ./path/to/pkg -run TestName`.
